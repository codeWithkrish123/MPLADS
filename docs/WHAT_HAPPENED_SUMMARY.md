## 🔍 Detailed Explanation

### **What is GitHub?**
GitHub is like a cloud storage for code (like Google Drive but for developers). It:
- ☁️ Stores your code safely on servers
- 📋 Keeps complete version history
- 👥 Allows team collaboration
- 🔍 Lets others review your code
- 🚀 Makes deployment easy

## 🏗️ Git Concepts Simplified

### **Branch**
Think of it like a road with multiple lanes:
```
Main lane (main branch) - Safe, production code
Your lane (feature/mplad-frontend) - Your changes
```

### **Commit**
Like saving a document with a version number:
```
Version 1: "Initial setup"
Version 2: "Added hero section"
Version 3: "Added emblem" ← You are here (745aa19)
```

### **Push**
Uploading to cloud storage:
```
Your Computer → (Upload) → GitHub Servers
```

### **Pull Request**
Asking permission to merge:
```
"Hey, can you review my changes and merge them?"
```
