### Colors Used
```

Light Background:  slate-50 to slate-100 (Clean)
Text:              slate-900 & slate-600 (Readable)
```

### Typography
```
Section Label:     11px BOLD UPPERCASE (Pill badge)
Main Title:        42px-48px FONT BLACK (Device-responsive)
Description:       18px text-slate-600 (Readable)
Card Titles:       16px font-bold (Clear)
Card Details:      14-18px font-bold (Prominent)
FAQ Questions:     15px font-bold (Clear)
FAQ Answers:       13px leading-relaxed (Easy reading)
```

### Layout & Spacing
```
Section Padding:   py-20 px-4 (Generous vertical space)
Card Grid:         1 col (mobile) → 2 col (tablet) → 4 col (desktop)
FAQ Grid:          1 col (mobile) → 2 col (tablet/desktop)
Card Gap:          gap-6 (Breathing room)
Card Padding:      p-8 (Spacious interior)
Responsive:        Mobile-first approach with proper breakpoints
```

### Animations
```
Card Hover:        -translate-y-1 (Lift up)
Icon Hover:        scale-110 (Enlarge)
Shadow Hover:      shadow-md → shadow-xl (Depth)
All Transitions:   duration-300 (Smooth 300ms)
Button Hover:      Color change + shadow
```
