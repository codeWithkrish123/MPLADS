ANIMATION EFFECTS:
═══════════════════════════════════════════════════════════════════════════════

PAGE LOAD:
  1. Header fades in (200ms)
  2. Cards slide up from bottom (400ms staggered)
  3. Charts fade in (300ms)

TAB SWITCH:
  1. Current content fades out (200ms)
  2. New content fades in (200ms)

CARD HOVER:
  1. Card lifts up (-4px translate-y)
  2. Shadow increases (md → lg)
  3. All transitions smooth (300ms)

PROGRESS BAR:
  1. Continuously pulses
  2. Cycle time: 2 seconds
  3. From opaque to semi-transparent

CHART LOAD:
  1. Grid fades in
  2. Axes animate
  3. Data points appear
  4. Lines/bars draw in
