================================================================================
                    WHAT EACH COMMAND DOES
================================================================================

git status
  └─ Shows what files changed
  └─ Shows what's ready to push
  └─ Shows what's not ready yet

git add src/
  └─ Prepares src/ folder for push
  └─ Doesn't push yet, just prepares
  └─ "I'm ready to save these files"

git commit -m "message"
  └─ Creates a snapshot with your message
  └─ Saves locally on your computer
  └─ Still not on GitHub yet!

git push origin feature/mplad-frontend
  └─ Sends all commits to GitHub
  └─ FINALLY puts your code on GitHub!
  └─ Your team can see it now!
